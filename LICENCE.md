**Civilization 7 Companion** is a curated list of Civilization 7 open-source tools:

## ✨ Features

### ESP
- Turn Tracker — monitor turn progress and timers
- Resource Overlay — visualize strategic resources and yields
- Unit Manager — organize and review unit assignments
- City Planner — plan district and wonder placement

### Wallhack
- Map Overlay — enhanced map view with grid and coordinates
- Fog Notes — mark explored and unexplored areas
- Tile Inspector — review terrain and feature details

### Aimbot
- Save Manager — backup and restore game states
- Speed Control — adjust game speed for study (0.5x to 2x)
- Config Editor — tweak overlay settings and hotkeys
